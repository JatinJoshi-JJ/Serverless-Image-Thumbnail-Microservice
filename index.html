Request Lifecycle

4-Stage Serverless Execution Pipeline

Every HTTP invocation passes through deterministic validation, memory-stream decoding, and compression stages.

STAGE 01

Edge Gateway & CORS

Netlify Edge routes /api/thumbnail to the isolated function container and resolves CORS preflight headers.

STAGE 02

Buffer & MIME Gate

Fetches remote image stream or decodes Base64 into a Node.js Buffer, rejecting non-image payloads with HTTP 400.

STAGE 03

Sharp / libvips Resize

Extracts source dimensions and performs center-cropped resampling into WebP, JPEG, or PNG at 80% perceptual quality.

STAGE 04

JSON & Data URI Response

Returns structured telemetry, compression ratio savings, execution time in ms, and ready-to-render Data URI.

                    FAQ
                    

                        Frequently Asked Questions
                    

                


                

                    

                        
                            How does the microservice validate non-image payloads?
                            +
                        
                        

                            Before resizing, the function checks remote HTTP
                            Content-Type headers and runs
                            sharp(buffer).metadata() to
                            verify magic bytes. Plain text, HTML, or corrupted payloads
                            immediately return an
                            HTTP 400 Bad Request JSON
                            error.
                        

                    


                    

                        
                            Can frontend apps on another domain call
                                /api/thumbnail?
                            +
                        
                        

                            Yes. Every response includes
                            Access-Control-Allow-Origin: *
                            and responds to
                            OPTIONS preflight requests
                            with 204 No Content.
                        

                    


                    

                        
                            Why does the preview sandbox work even without a local Node
                                server?
                            +
                        
                        

                            When deployed on Netlify, requests hit the live Node.js + Sharp
                            serverless function at
                            /api/thumbnail. If opened
                            standalone in an offline preview, the client gracefully falls
                            back to an HTML5 Canvas encoder so you can test the exact same
                            JSON contract anywhere.
